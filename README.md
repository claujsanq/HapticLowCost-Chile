# HapticLowCost-Chile

## Project Overview

HapticLowCost-Chile is a project focused on the adaptation of the WoodenHaptics device using components and manufacturing resources available in Chile.

The project aims to develop a low-cost, accessible, and reproducible haptic device while documenting the mechanical design, electronic components, control software, assembly procedures, and experimental characterization.

## Objectives

- Adapt the original WoodenHaptics design to locally available components.
- Document component substitutions and engineering design decisions.
- Evaluate the manufacturing and assembly costs of the adapted device.
- Experimentally characterize the components and evaluate device performance.
- Provide technical documentation to support reproducibility and future developments.

## Repository Structure

- `hardware/`: Mechanical design and hardware documentation.
  - `CAD/`: Mechanical CAD models.
  - `Drawings/`: Technical drawings and manufacturing specifications.
  - `BOM/`: Mechanical and electronic bills of materials.
- `assembly/`: Assembly instructions and procedures.
- `software/`: Device communication and control software.
- `experiments/`: Experimental protocols, data, analysis scripts, and results.
- `docs/`: Technical documentation and design decisions.

## Project Status

This project is currently under development. The repository will be progressively updated as design, implementation, and experimental validation activities advance.
