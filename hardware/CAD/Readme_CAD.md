# CAD Files — Revision R1

This directory contains the mechanical CAD models of the adapted WoodenHaptics device, developed in Autodesk Inventor.

## Main Project and Assembly

| File | Description |
|---|---|
| `WoodenHaptics_Prototipo_MDF_R1.ipj` | Autodesk Inventor project configuration. |
| `WoodenHaptics_Prototipo_MDF_R1.iam` | Complete mechanical assembly of the haptic device. |

## Subassemblies

| File | Description |
|---|---|
| `Cuerpo_Base.iam` | Base assembly. |
| `Cuerpo_A.iam` | Body A assembly. |
| `Cuerpo_B.iam` | Body B assembly. |
| `Cuerpo_C.iam` | Body C assembly. |
| `Cuerpo_Cprima.iam` | Body C' assembly. |

## Individual Parts

The `Piezas/` directory contains the individual mechanical component models (`.ipt`) referenced by the assembly files.

## Opening the CAD Model

1. Download the complete CAD directory.
2. Open and activate the `.ipj` project file in Autodesk Inventor.
3. Open `WoodenHaptics_Prototipo_MDF_R1.iam`.

Preserve the original file names and directory structure to avoid breaking assembly references.
